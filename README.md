# CleaningDataSQL

This project focuses on cleaning and preparing raw data using MySQL before analysis.
The objective was to improve data quality by identifying inconsistencies, removing errors, and standardising the dataset to make it reliable and analysis-ready.
SQL Techniques Used:
DELETE to remove duplicate records
UPDATE to correct inconsistent values
TRIM() to clean unwanted spaces
ALTER TABLE to remove unnecessary columns
Handling NULL and blank values
Data standardisation for consistency
Through this project, I strengthened my understanding of the importance of data cleaning in the analysis process. Clean and structured data ensures more accurate insights and better decision-making.
This project demonstrates my ability to use SQL for real-world data preparation and transformation.
